# NFC Tag Setup for Quick Draw Tarot

Each NFC tag should store a direct URL to a card page. When tapped, the phone opens that page in the browser.

Example URLs:

- `https://zoecsj.github.io/Quick-Draw-Tarot/cards/the-fool.html`
- `https://zoecsj.github.io/Quick-Draw-Tarot/cards/ace-of-cups.html`
- `https://zoecsj.github.io/Quick-Draw-Tarot/cards/two-of-swords.html`

## Quick setup steps

1. Open any NFC writing app on your phone (for example: NFC Tools).
2. Choose to write a URL/URI record.
3. Paste the exact card URL for that physical tarot card.
4. Write to the NFC tag.
5. Test by tapping the tag and confirming the correct card page opens.

Tip: keep one URL per tag and label each physical card/tag pair while you program them.
